# Contributing

Include repeatable SQLite or Python checks with schema changes. Use synthetic observations for test cases. Record which source schema version and projection guarantees a change affects. Keep personal exports, seed catalogues, application source and private generation inputs out of this candidate.

Run `python3 -m unittest discover -s tests -v` from the repository root. The private maintainer workflow regenerates the versioned schema and checks parity against native TYR exports.

Contribute new fictional scenarios using the [scenario configuration](scenarios/README.md). Verify the observations and keep evaluator truth out of agent bundles.

## Contribution rights

Submit changes you have the right to contribute. Apache License 2.0 Section 5 governs intentionally submitted contributions, subject to its exceptions and any applicable separate agreement. Identify transcribed or adapted third-party material, its source, and its license and attribution requirements in your contribution. Use fictional observations for tests and examples. Keep personal exports and private evaluator materials out of submissions.
